# v2.1.0 v0.0.2 改进实验套件

本版本将“当前最优 v0.0.2 LeakyReLU”后续构建方向落成统一实验脚本，不覆盖原始训练、测试和提交入口。

## 目标

- 保留 v0.0.2 LeakyReLU 低 FA、高 IoU 的优势。
- 通过阈值细扫、样本池复训、召回增强、STC 参数网格、传统后处理融合和 LeakyReLU 斜率微调，尝试补回 PD/召回。
- 所有新产物写入 `log/versions/v2.1.0-v002-improvement-suite/`。

## 文件

- `v002_improvement_suite.py`：统一实验入口。
- `run_plan.txt`：6 个完整训练实验命令，路径按 Docker 容器 `/root/EV-UAV` 生成。
- `configs/`：每个训练变体的 YAML 配置。
- `results/planned_experiments.csv`：训练实验清单。
- `models/`：训练后模型保存位置。
- `submission/`：阈值提交文件输出位置。

## 推荐执行顺序

1. 阈值细扫，不重训：

```bash
conda activate evuav
cd /root/EV-UAV
python log/versions/v2.1.0-v002-improvement-suite/v002_improvement_suite.py threshold-scan --thresholds 0.70:0.95:0.01
```

2. 基于最佳阈值生成验证集提交包：

```bash
python log/versions/v2.1.0-v002-improvement-suite/v002_improvement_suite.py submission --threshold 0.86 --name v002_best_threshold
```

3. 传统后处理融合扫描，不重训：

```bash
python log/versions/v2.1.0-v002-improvement-suite/v002_improvement_suite.py fusion-scan
```

4. 训练实验，按 `run_plan.txt` 顺序逐个执行：

```bash
bash -c "$(sed -n '1p' log/versions/v2.1.0-v002-improvement-suite/run_plan.txt)"
```

## 训练变体

| 变体 | 目的 |
|------|------|
| `v002_d_pool_retrain` | 使用 v0.1.0 D 组时空结构样本池复训 LeakyReLU。 |
| `v002_recall_pos2_dice02` | 使用正类权重 2.0 + Dice 0.2 增强正类召回。 |
| `v002_stc_t3` | 将 STC 时间窗口从 5 缩小到 3，观察是否减少漏检。 |
| `v002_stc_t7` | 将 STC 时间窗口从 5 扩大到 7，观察时序约束是否提升稳定性。 |
| `v002_slope_0p005` | LeakyReLU negative_slope=0.005。 |
| `v002_slope_0p02` | LeakyReLU negative_slope=0.02。 |

## 注意事项

- 阈值扫描、提交生成、融合扫描需要 Docker/conda 环境中的 torch、spconv 和 HAIS_OP。
- 宿主机仅验证了脚本语法和轻量配置生成。
- 训练类命令会消耗较多 GPU 时间，应优先跑 `threshold-scan` 和 `fusion-scan`，再决定是否全量训练。
