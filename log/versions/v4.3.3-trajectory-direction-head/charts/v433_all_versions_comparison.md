## 结论

- **v4.3.3 IoU=0.745085 超越 v3.1.3 (0.717086)，成为新 SOTA。** 方向聚合仍未实际生效（`direction_aggregation_skipped=true`，Bottleneck 体素数 >2000），v4.3.3 的提升来自 `L = L_main + 0.3*L_traj + 0.2*L_dir` 的 Dice 辅助损失 + 方向预测头辅助监督。
- v4.3.3 的 seg_acc=0.846442 仅次于 v4.2.0 (0.888621)；PD=0.815204 在 v4.x 系列中居中；FA=0.000242 在 v4.x 系列中居中，高于 v4.2.0 和 v3.1.3 但远低于 v4.1.0。
- v4.2.0 仍保持 seg_acc (0.888621) 和 PD (0.863924) 两项最高，但 IoU 大幅落后于 v4.3.3。
- v2.1.0 仍保持最低 FA (0.000108761)，为 4 通道架构下的虚警最优版本。
- v3.1.3 (IoU=0.717086, FA=0.000152564) 曾被超越但仍为强基线，FA 在 v4.x 中仅次于 v4.2.0。
- 后续方向：若能使方向聚合模块实际生效（降低体素阈值），有望进一步提升 IoU；同时可探索 Dice 权重调优或引入负样本策略进一步压低 FA。
