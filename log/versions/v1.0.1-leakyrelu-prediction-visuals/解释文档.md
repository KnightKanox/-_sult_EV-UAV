# v1.0.1 LeakyReLU 预测可视化说明

## 数据来源

本版本处理以下事件数据：

- `/root/EV-UAV-dataset/train/*.npz`：99 个训练样本
- `/root/EV-UAV-dataset/val/*.npz`：24 个验证样本

宿主机对应数据目录为：

- `/media/sult/山江冬夏/训练集、验证集/train/*.npz`
- `/media/sult/山江冬夏/训练集、验证集/val/*.npz`

每个 `.npz` 内包含 `ev`、`ev_loc`、`evs_norm`。其中：

- `ev`：原始事件流，字段包含 `x, y, t, p, label, name`
- `ev_loc`：模型 voxelization 使用的事件位置索引
- `evs_norm`：模型输入特征，前 4 列用于推理，第 5 列为标签，第 6 列为事件编号

## 模型与运行环境

本版本使用 Docker 容器 `evuav` 内的 EV-UAV 环境执行推理。

- 项目目录：`/root/EV-UAV`
- 数据目录：`/root/EV-UAV-dataset`
- Python 环境：`/root/exit/envs/evuav/bin/python3`
- 模型结构：`/root/EV-UAV/model/evspsegnet.py` 与 `/root/EV-UAV/model/basemodel.py` 中的 LeakyReLU(negative_slope=0.01) 版本
- 模型权重：`/root/EV-UAV/log/model_leaky_relu/best_iou_seed37.pt`
- 推理阈值：`0.9`

宿主机 `EV-UAV/**/*.pt` 未找到权重，因此按任务要求继续在 Docker 容器内查找，最终使用上述容器内权重。该路径与历史 `v0.0.2` LeakyReLU 训练日志记录的 `log/model_leaky_relu/best_iou_seed37.pt` 一致。

## 生成方法

生成脚本位于：

```text
/media/sult/山江冬夏/训练集、验证集/EV-UAV/log/versions/v1.0.1-leakyrelu-prediction-visuals/generate_leakyrelu_prediction_visuals.py
```

执行流程：

1. 在 Docker `evuav` 容器内加载 LeakyReLU 模型和 `best_iou_seed37.pt` 权重。
2. 逐个读取 train/val 的 `.npz` 文件。
3. 使用 EV-UAV 原始 voxelization、spconv SparseConvTensor 和 `p2v_map` 将 voxel 预测映射回事件级预测。
4. 对模型输出概率使用阈值 `0.9` 得到二分类预测标签。
5. 为每个样本保存事件级预测 CSV。
6. 复用 v1.0.0 的事件空间投影思路生成底图，再把模型预测为正类的事件所在像素覆盖为蓝色。

## 蓝色含义

输出图采用白色背景和事件投影底图：

- 白色：该像素没有事件
- 浅红/灰蓝底色：原始事件空间投影，表达不同极性和事件密度
- 蓝色 `RGB(0, 80, 255)`：v0.0.2 LeakyReLU 模型预测为正类的事件投影位置

同一像素内只要存在至少一个预测正类事件，该像素即覆盖为蓝色。

## Train 真实标注与预测对比

训练集 `.npz` 的 `ev` 字段中包含真实标注 `label`，因此额外生成了 train 集的 GT vs Prediction 对比图：

- 红色 `RGB(255, 40, 40)`：真实标注为正类、模型未预测为正类的位置
- 蓝色 `RGB(0, 80, 255)`：模型预测为正类、真实标注不是正类的位置
- 紫色 `RGB(180, 0, 220)`：真实标注和模型预测均为正类的位置
- 灰度底图：原始事件空间投影

对比图只针对 train 集生成，因为 train 集包含可直接用于对齐的真实事件级标注。
