# npz 事件数据转图片说明

## 原始数据是什么

本目录处理的数据来自：

- `/media/sult/山江冬夏/训练集、验证集/train/*.npz`
- `/media/sult/山江冬夏/训练集、验证集/val/*.npz`

这些 `.npz` 文件不是普通图片，而是 NumPy 压缩数组包。每个文件内部包含 3 个数组：

- `ev.npy`：原始事件流，字段为 `x, y, t, p, label, name`
- `ev_loc.npy`：事件位置/时间索引形式
- `evs_norm.npy`：归一化后的事件特征

其中用于生成图片的是 `ev.npy`。它的每一条记录代表一个事件：

```text
x,y,t,p,label,name
76,226,0.0,1,1,1
76,224,0.166,0,1,1
75,224,1.108,0,1,1
```

字段含义：

- `x`：事件横坐标
- `y`：事件纵坐标
- `t`：事件时间戳
- `p`：事件极性，通常表示亮度变化方向，取值为 `0` 或 `1`
- `label`：事件标签
- `name`：样本或类别相关编号

## 转换成图片的方法

事件相机数据不是一帧天然图像，而是一串按时间发生的事件。因此这里采用“空间投影”的方法生成静态图片：

1. 读取每个 `.npz` 文件中的 `ev.npy`。
2. 遍历所有事件，取出 `(x, y, p)`。
3. 按坐标 `(x, y)` 把事件累积到二维画布上。
4. 对不同极性的事件分别计数：
   - `p = 1` 记为正极性事件
   - `p = 0` 记为负极性事件
5. 以每个像素位置的事件计数强度生成颜色。
6. 先输出标准 `PPM` 图片文件。
7. 再使用 Pillow 将 `.ppm` 转换为同名 `.jpg`，方便常规图片查看器直接打开。

## 图片颜色含义

生成图片采用白色背景：

- 白色：该位置没有事件
- 偏红/深色：该位置正极性事件较多
- 偏蓝/深色：该位置负极性事件较多
- 颜色越深：该位置累计事件越多

因为这是把完整事件流压缩投影到一张静态图，所以图片表达的是事件在空间上的总体分布，而不是某一个具体时刻的画面。

## 输出目录

批量图片输出在：

```text
log/versions/v1.0.0-npz-readable-export/images/
```

目录结构：

```text
images/
  train/
    train_000_event.ppm
    train_001_event.ppm
    ...
  val/
    val_000_event.ppm
    val_001_event.ppm
    ...
  image_index.csv
  image_index_jpg.csv
```

其中：

- `images/train/`：训练集 99 个 `.npz` 对应的事件投影图，同时保留 `.ppm` 和 `.jpg`
- `images/val/`：验证集 24 个 `.npz` 对应的事件投影图，同时保留 `.ppm` 和 `.jpg`
- `images/image_index.csv`：PPM 图片索引，记录来源文件、输出图片路径、图片宽高和事件数量
- `images/image_index_jpg.csv`：JPG 图片索引，记录 `.ppm` 到 `.jpg` 的对应关系、宽高

## 单文件可读化结果

为了方便检查 `train_000.npz` 的具体结构，保留了单文件表格导出：

```text
results/
  train_000_ev.csv
  train_000_ev_loc.csv
  train_000_evs_norm.csv
  train_000_summary.txt
  train_000_event.ppm
```

这些文件用于查看 `train_000.npz` 的原始事件表、位置索引、归一化特征、摘要和单张事件图。

## 注意事项

- `PPM` 是标准图片格式，但部分图片查看器默认不会关联该扩展名；如果无法直接打开，可以用支持 PPM 的查看器或图像工具打开。
- 当前图片是完整事件流的空间投影，不包含时间维度动画。
- 如果需要观察事件随时间变化，可以后续按时间窗口切分，每个窗口生成一张图，再合成为序列或视频。
